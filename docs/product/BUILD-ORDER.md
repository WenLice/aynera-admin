# ElAris build order

**Website first.** Mobile comes after public web and admin support the concierge pilot.

## Phase sequence

| Phase | Deliverable | Outcome |
|-------|-------------|---------|
| **0** | Figma + design tokens | Testable prototype spec |
| **1** | Public website | Landing, apply, waitlist, safety/legal pages |
| **2** | Admin portal | Applicant review, cohort view, safety intake |
| **3** | Thin API | Applications, profiles, approval status |
| **4** | Concierge pilot | Manual introductions, funnel measurement |
| **5** | Mobile app | Onboarding, discovery, chat |
| **6** | Meeting layer | Date plan, Share Date, feedback |
| **7** | Focus → Together | Differentiator features |

## Website first — public web pages

- Home / positioning
- How it works
- Apply / join waitlist (Delhi and Bangalore)
- Safety centre
- Privacy, terms, grievance contact
- Account deletion request

## Website first — admin portal

- Moderator login
- Applicant queue (approve / reject / waitlist)
- Profile review
- Cohort dashboard
- Safety case intake

## Exit gate before mobile

- [ ] 200+ qualified waitlist applicants
- [ ] Admin can review a profile in under 2 minutes
- [ ] Manual introductions producing conversations
- [ ] Evidence of safe meeting intent or outcomes
- [ ] Women's advisory cohort signed off on apply + safety copy
